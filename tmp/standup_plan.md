# Daily Standup Meeting Plan

## Overview

**Duration:** 15 minutes max  
**Frequency:** Daily  
**Format:** Standing (or video call) — no laptops, no slides

---

## Agenda & Time Allocations

| Section | Time | Description |
|---------|------|-------------|
| **Opening** | 30 sec | Quick greeting, confirm meeting is still on track |
| **Round Robin** | 12 min | Each member answers 3 questions (~1 min/person for 12 people) |
| **Wrap-up** | 2 min | Action items, blockers to escalate, next standup |
| **Buffer** | 30 sec | Transition to next activity |

> ⏱ Total: **15 minutes** — no exceptions.

---

## The 3 Standard Questions

Every team member answers these same three questions:

1. **What did I complete yesterday?**  
   Focus on deliverables, not activities. Be specific.

2. **What will I work on today?**  
   State your top priority. Keep it scoped.

3. **What is blocking me?**  
   Identify impediments. Flag anything that needs help.

---

## Team Member Template

> Copy this template and fill it out **before** the meeting. Reading from it keeps you on track.

```
### [Your Name]

**Yesterday:**
- Completed: [What you finished]
- Delivered: [Any PRs, docs, deployments, etc.]

**Today:**
- Priority: [Your #1 focus]
- Plan: [Brief description of what you'll do]

**Blockers:**
- [Any issues, dependencies, or help needed]
- If none: "No blockers."
```

**Example:**
```
### Alex

**Yesterday:**
- Completed: Finished user auth API endpoints
- Delivered: PR #142 merged

**Today:**
- Priority: Write integration tests for auth module
- Plan: Cover login, logout, and token refresh flows

**Blockers:**
- Waiting on design team for error message copy (expected EOD)
```

---

## Tips for Keeping Standups Under 15 Minutes

### Before the Meeting
- **Fill out the template in advance** — no reading from scratch
- **Keep updates brief** — aim for 60 seconds per person
- **No problem-solving in the standup** — if a topic needs discussion, take it offline

### During the Meeting
- **Stand up** — physical discomfort naturally keeps things short
- **Use a timer** — visible countdown creates healthy urgency
- **Rotate the facilitator** — shared ownership keeps energy up
- **Parking lot for tangents** — if a discussion derails, note it and continue

### After the Meeting
- **Document blockers only** — detailed updates go in your project tool
- **Follow up on escalated issues** — assign owners, don't leave them hanging
- **Solicit feedback monthly** — ask the team: "Is the standup working for you?"
