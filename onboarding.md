## Day 1 — Setup & Introductions

### Environment & Access
- [ ] Receive laptop and configure (OS setup, terminal, editor)
- [ ] Set up email, Slack, and calendar
- [ ] Create/access accounts: GitHub, CI/CD, cloud console, Jira
- [ ] Install required tools: IDE, Docker, CLI tools, browser extensions
- [ ] Verify connectivity to internal services and databases

### Team & Culture
- [ ] 1:1 meeting with mentor (expectations, goals, communication norms)
- [ ] Meet the team — brief intro round in Slack or standup
- [ ] Review team charter, coding standards, and on-call rotation
- [ ] Walk through the engineering handbook and docs site

---

## Week 1 — Getting Started

### Repository & Workflow
- [ ] Clone and run the main application locally (follow `README.md`)
- [ ] Run the test suite and confirm all tests pass
- [ ] Set up pre-commit hooks and linting
- [ ] Review recent pull requests to understand code review norms

### First Contribution
- [ ] Pick a "good first issue" (labeled `good-first-issue` or `onboarding`)
- [ ] Submit first PR — mentor will review and guide
- [ ] Merge first PR (aim for **Friday** of week 1)

### Documentation
- [ ] Read architecture overview and system diagrams
- [ ] Familiarize with data models, API endpoints, and key services
- [ ] Bookmark key docs: [link 1], [link 2], [link 3]

---

## Month 1 — Independence

### Development
- [ ] Complete 3–5 PRs (including at least 1 with tests)
- [ ] Understand and update documentation where needed
- [ ] Deploy at least one change to staging/production (with guidance)

### Code Review & Collaboration
- [ ] Participate in code reviews — review at least 5 PRs from others
- [ ] Attend sprint planning, standups, and retros as a contributor
- [ ] Practice writing meaningful commit messages and PR descriptions

### Growth
- [ ] Set 30/60/90-day goals with mentor and manager
- [ ] Identify one area of the codebase to own (e.g., a service, feature, or tooling)
- [ ] Complete any required security, compliance, or training modules
- [ ] Schedule a 30-day retrospective with mentor to discuss progress and feedback
